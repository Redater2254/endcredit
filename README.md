# endcredit

**SOOP 방송용 커스텀 엔딩크레딧 제작 · 송출 프로그램**

방송이 끝날 때, 오늘 함께해준 사람들의 이름을 영화 엔딩크레딧처럼 올려보내는 도구입니다.<br>
채팅 순위 · 별풍선 · 신규 구독자 같은 **오늘의 실제 기록**을 자동으로 모아서 화면에 띄웁니다.

`Windows` · `Electron` · `SOOP OpenAPI`

## 왜 만들었나

이미 비슷한 도구가 몇 개 있지만, 대부분 **만든 사람의 방송에 맞춰져 있어** 남이 쓰면 커스텀이 거의 불가능합니다.
색 하나, 문구 하나 바꾸려 해도 손댈 수가 없죠.

endcredit 은 그 반대로 만들었습니다. **모든 것이 사용자 것**입니다 —
글꼴·색·위치·효과·배경음악·효과음까지 전부 바꿀 수 있고,
완성한 구성은 **파일 하나로 묶어 다른 스트리머에게 그대로 줄 수 있습니다.**

## 기능

### 📊 오늘의 기록을 자동으로 모읍니다

방송 중에 켜두면 SOOP 채팅 서버에 붙어 이벤트를 받아 실시간으로 집계합니다.

| 순위 | 명단 | 합계 |
|---|---|---|
| 채팅을 많이 친 사람 | 오늘의 신규 구독자 | 총 채팅 수 |
| 이모티콘을 많이 쓴 사람 | 구독 갱신 (개월 수) | 참여자 수 |
| 별풍선을 많이 쏜 사람 (도전·대결미션 포함) | 오늘의 신규 팬클럽 | 총 별풍선 |
| 서포트 스티커 | 열혈팬 승급 | 총 스티커 |
| 선물을 많이 한 사람 | 플러스 구독 선물 | 이모티콘 사용 수 |
| | 오늘의 신규 애청자 | 방송 시간 |

그밖에 **오늘 처음 채팅한 사람**, **한 번에 가장 크게 쏜 후원** 같은 것도 잡습니다.

- 모든 이벤트는 **줄 단위 로그 파일로 계속 쌓입니다.** 앱이 중간에 꺼져도 다시 켜면 그 로그로 집계를 복원합니다.
- 같은 사람이 닉네임 뒤에 `(2)` 같은 표시를 달고 들어와도 **한 사람으로 셉니다.**
- **도전미션·대결미션에 쓴 별풍선도 별풍선 순위에 함께 들어갑니다.** 미션에 쏜 것만 따로 빠지면 실제로 가장 많이 쏜 사람이 순위에서 밀리기 때문입니다.
- 스트리머 본인의 채팅은 순위에서 빠집니다.

### 🎨 슬라이드 편집기

파워포인트처럼 **장(슬라이드)** 을 만들고, 그 안에 요소를 자유롭게 배치합니다.

- **요소 6종** — 텍스트 / 이미지 / 순위 목록 / 등수 하나 / 도형 / **🚂 기차**
- **명단 자동 흐름** — `순위 목록` 의 열 수를 **`자동`** 으로 두면 신문 단처럼 흘러갑니다. 위에서 아래로 쌓다가 상자 끝에 닿으면 **다음 열 맨 위로 넘어가서** 계속 쌓입니다. 새 열이 생기는 쪽(오른쪽/왼쪽), 가로로 흐르다 줄바꿈(아래/위)도 고를 수 있고, 줄 간격·열 간격을 따로 줍니다. 신규 구독자·팬클럽처럼 **몇 명일지 모르는 명단**을 열 수 맞춰가며 고칠 필요가 없습니다
- **그림은 끌어다 놓으면 됩니다** — 탐색기에서 캔버스로 바로 끌어오세요. 놓은 자리에, **원래 비율 그대로** 들어갑니다. 여러 장을 한 번에 놓아도 되고 되돌리기는 한 번이면 됩니다
- **파일 창은 지난번 폴더에서 열립니다** — 이미지·소리·프리셋을 **따로** 기억하므로, 음악을 넣은 뒤 그림을 고르려는데 음악 폴더가 열리는 일이 없습니다
- **자유 배치** — 끌어서 이동, `Ctrl+T` 자유 변형(크기·회전), 화살표 키로 1px 미세 이동
- **자석(스냅)** — 다른 요소나 화면 중앙에 착 붙습니다. `Ctrl` 을 누르면 잠시 꺼집니다
- **묶기** — 여러 요소를 폴더로 묶어 한 덩어리로 다룹니다 (포토샵 레이어와 같은 방식)
- **고급 개체(스마트 오브젝트)** — 고른 요소들을 **레이어 한 줄로 접습니다**. 접히면 여느 요소처럼 끌고 늘이고 돌릴 수 있고(안쪽 글자 크기까지 함께 커집니다), **두 번 누르면 그 안이 자기 캔버스를 가진 화면으로 열려** 원래 좌표 그대로 고칠 수 있습니다. `Ctrl+J` 로 복제한 사본은 **원본과 연결되어** 한 곳만 고쳐도 전부 바뀝니다(요소칸에 `⧉2` 표시). 다시 `고급 개체 해제` 하면 지금 크기 그대로 요소들로 풀립니다
- **레이어 병합(`Ctrl+E`)** — 여러 요소를 **한 장의 이미지로 굽습니다**(포토샵 레이어 병합). 모양은 그대로지만 데이터·효과가 그 순간 값으로 고정되어 더는 바뀌지 않으니, 배경 장식처럼 굳혀도 되는 조합에 쓰세요
- **정렬** — 왼쪽·가운데·오른쪽·위·중간·아래 맞춤, 균등 분배
- **범위 선택** — 빈 곳을 드래그해서 여러 개를 한 번에 잡습니다. **올가미(`L`)** 로 자유곡선을 그려 비스듬한 무리를 고를 수도 있습니다
- **도형은 끌어서 그립니다(`R`)** — 도구 막대의 `도형` 을 누르면 사각형·타원·선을 고르는 칸이 나오고, 캔버스에 끌면 그 자리 그대로 놓입니다(`Shift` 로 정사각형·정원, `R` 을 연달아 누르면 종류가 넘어갑니다). 그냥 한 번 누르면 기본 크기로 놓입니다
- **도형 꾸미기** — 글자와 같은 항목을 도형에도 줍니다. **그라데이션**(두 색·방향), **테두리 여러 겹**(굵기·색), **그림자 여러 겹**(색·불투명도·각도·거리·흐림), 모서리 둥글기
- **이미지 꾸미기** — 테두리(액자)와 그림자를 겹겹이. 이미지 그림자는 **상자가 아니라 그림 모양을 따라갑니다** — 배경이 뚫린 PNG 면 인물 윤곽 그대로 그림자가 집니다 (무거워서 세 겹까지)
- **요소칸 우클릭·잠금** — 요소 목록에서 줄을 우클릭하면 잠금·숨김·순서·효과 복사/붙여넣기·고급 개체 변환을 그 자리에서. 고급 개체 줄은 두 번 누르면 내용이 열립니다. 잠근 요소는 캔버스에서 움직이지 않습니다
- **배경 이미지** — 장마다 사진을 깔고 맞춤(채우기·전체 보기·늘이기)·불투명도·흐림을 조절합니다. 한 번에 모든 장에 적용도 됩니다
- **재생 타임라인** — 캔버스 아래 막대에 장이 길이대로 늘어섭니다. **아무 데나 찍으면 그 순간에 화면을 세워 놓고** 볼 수 있어, 1분 40초 지점 효과 하나를 고치려고 처음부터 재생할 필요가 없습니다. 캔버스를 누르거나 `Esc` 로 편집으로 돌아옵니다
- **글자 자동 맞춤** — 상자를 넘치면 글자 크기를 줄여 맞춥니다. 닉네임 길이가 제각각이라 순위·기차 칸이 터지는 걸 막아줍니다 (글자 속성의 `상자에 맞게 크기 줄이기`)
- **글자 꾸미기** — **칠**(단색 · 두 색 그라데이션 + 방향) · **외곽선**(두께·색, 글자 뒤로 그려서 두꺼워도 안 뭉갭니다) · **그림자**(색·가로·세로·흐림) · **배경 판**(색·둥글기·여백, 글자에 딱 붙는 띠). 넷을 겹쳐 쓸 수 있어 방송 화면 위에서도 또렷합니다
- **화면 크기** — `1920×1080` 말고도 **세로 9:16(쇼츠)**·정사각·720p 를 고를 수 있습니다. 바꾸면 배치는 %라 그대로 따라오고 글자 크기는 세로 비율만큼 함께 조정됩니다 (빈 곳을 눌러 나오는 슬라이드 속성 맨 위)
- **되돌리기** — 드래그 한 번이 히스토리 한 줄 (100단계)
- 좌표는 전부 화면 대비 **%** 라서 해상도가 바뀌어도 배치가 그대로 맞습니다
- **밝은 테마 / 어두운 테마** — `Ctrl+Shift+L` 로 바꿉니다 (방송에 나가는 화면은 그대로입니다)
- **UI 크기** — 머리말 오른쪽 `%` 버튼. 기본값 **자동**은 모니터 해상도·배율에 맞춰 앱 크기를 정하고, 창을 다른 모니터로 옮기면 그 모니터에 다시 맞춥니다. 직접 80~150% 로 고정할 수도 있습니다 (방송에 나가는 화면은 그대로입니다)
- **좁은 화면에서도 안 무너집니다** — 패널을 아무리 넓게 벌려두어도, 화면이 좁아지면 캔버스 자리를 지키는 선까지 자동으로 조여집니다. 넓은 모니터로 돌아오면 원래 배치가 그대로 복구됩니다

### ✍️ 글자를 그 자리에서 고칩니다

텍스트를 **두 번 클릭**하면 캔버스 위에서 바로 편집됩니다. 포토샵처럼 **일부만 드래그해서** 색·크기·굵기를 따로 줄 수 있습니다.

> `1등` 은 노랗고 크게, 이름은 희게, 횟수는 작고 회색으로 — 한 줄 안에서

### 🔢 데이터 필드

글 안에 `{chatRank.1.name}` 같은 자리표시자를 넣으면 방송이 끝날 때 실제 값으로 바뀝니다.

```
오늘의 수다왕은 {chatRank.1.name} 님! ({chatRank.1.value})
```
→ `오늘의 수다왕은 밤샘코딩러 님! (247회)`

- 순위는 몇 등까지든 (`{balloonRank.7.name}`)
- 명단 전체를 한 번에 (`{newSubscribers.list}`)
- 합계도 (`{total.messages}`, `{total.duration}`)
- **오늘 날짜·시각** (`{now.year}년 {now.month}월 {now.day}일 {now.hour}:{now.minute}` → `2026년 7월 26일 22:19`). 크레딧을 튼 순간의 시계를 씁니다 — 시·분은 두 자리로 채워져서 `21:05` 처럼 나옵니다
- 아래 **데이터 필드** 칸에서 끌어다 놓으면 그 자리에 만들어집니다
- **샘플 데이터**를 켜면 시청자 없이도 완성된 모습을 볼 수 있습니다

### ✨ 효과

| 종류 | 개수 | 예 |
|---|---|---|
| **등장** | 19 | 페이드 · 뽀잉 · 통통 · 젤리 · 스프링 · 회전 등장 · 흐림 해제 · **타자기** … |
| **강조** (반복) | 5 | 네온 · 둥실 · 흔들 · **흐르는 자막** … |
| **퇴장** | 11 | 페이드 아웃 · 쪼그라듦 · 좌우로 퇴장 · 돌며 사라짐 · 떨어짐 … |
| **화면 전체** | 11 | 🎊 색종이 · 🎉 색종이 대포 · 🎆 불꽃놀이 · ✨ 반짝이 · ❄️ 눈 · 🌸 꽃잎 · 💗 하트 · 🫧 비눗방울 · 💫 빛줄기 · ⚡ 번쩍 · 🌑 가장자리 어둡게 |
| **직접 만들기** | 무제한 | 키프레임 + 속도 곡선 편집기 ([아래](#-효과를-직접-만듭니다)) |

- **등장·강조·퇴장은 서로 다른 칸**이라 한 요소에 셋 다 걸 수 있습니다 — 왼쪽에서 들어와, 반짝이다가, 오른쪽으로 나가기
- **타자기**는 글자가 왼쪽부터 한 칸씩 찍히고, **흐르는 자막**은 뉴스 하단 자막처럼 오른쪽에서 왼쪽으로 계속 흘러갑니다 (가로로 넓은 글상자에 잘 맞습니다)
- **🚂 기차**는 효과가 아니라 **요소**입니다 — 수다왕·별풍선 순위 같은 데이터를 칸마다 한 명씩 태우고 화면을 **한 번** 가로지릅니다(반대편 화면 밖에서 나타나 반대쪽 밖으로 완전히 빠져나갑니다. 반복하지 않습니다). 칸에는 **등수 · 이름 · 수치**가 함께 실립니다(각각 끄고 켜고, 늘어놓는 차례도 고릅니다 — 등수는 태우는 차례와 무관하게 늘 원래 순위입니다). 글자 크기와 **등수·수치의 상대 배율**, 글자가 놓이는 **영역의 폭·세로 위치**, 그리고 **칸 자체의 가로:세로 비율**까지 조절합니다 — 글이 길면 칸부터 넓히면 됩니다. 칸 이미지는 **양 끝 칸**(한 장 — 마지막 칸엔 좌우로 뒤집혀 붙습니다)과 **가운데 칸**(여러 장, 돌아가며)으로 나눠 정하고, 칸 수·정렬 순서(1→N / N→1)·진행 방향(좌↔우)·지나가는 시간·칸 위 장식(위치·크기까지)·칸 강조 효과도 속성에서 정합니다. 장 길이는 기차가 다 지나갈 때까지 자동으로 늘어납니다
- **묶음에는 묶음만의 효과**를 겁니다. 덩어리가 통째로 떠오르는 동안 그 안에서 글자가 하나씩 튀어나오는 식으로, 묶음 효과와 안쪽 요소 효과가 서로를 덮지 않고 겹쳐 재생됩니다
- 효과 라이브러리에서 타일을 **끌어다 놓으면** 적용됩니다. 마우스만 올려도 그 자리에서 미리 재생됩니다
- 화면 효과는 입자 양·길이·시작 지연을 따로 조절합니다
- 장 전환 효과도 따로 있습니다

### 🎬 효과를 직접 만듭니다

고르는 것으로 부족하면 **직접 만듭니다.** 효과 라이브러리 맨 앞의 **효과 만들기** 칸을 누르면 **전용 창**이 열립니다. 프리미어 프로의 «효과 컨트롤» 과 같은 방식입니다.

크레딧 편집 화면을 가리지 않는 별도 창이라, **크레딧을 보면서 효과를 다듬을 수 있습니다.**

**움직일 수 있는 값** — 여섯 줄, 각각 자기 트랙을 갖습니다.

| 줄 | 값 | |
|---|---|---|
| **위치** | `X` `Y` | 요소 자기 크기 대비 % — 큰 제목에 걸든 작은 글씨에 걸든 같은 느낌 |
| **크기** | `X` `Y` | 가로·세로 배율을 따로 |
| **회전** | | 도 단위 (몇 바퀴도 가능) |
| **기울이기** | `X` `Y` | 한쪽으로 밀어 눕히는 변형 |
| **불투명도** | | |
| **흐림** | | |

- 줄 왼쪽의 **⏱ 를 켜면** 그 줄이 움직이기 시작합니다. 켜지 않은 줄은 효과에 아예 관여하지 않습니다
- **재생 헤드를 옮기고 숫자를 바꾸면 그 자리에 키프레임이 찍힙니다.** 트랙 위 `+` 를 눌러도 됩니다
- **파란 숫자를 끌면 값이 바뀌고, 누르면 고쳐 씁니다** — 지우고 다시 치는 것보다 훨씬 빠릅니다
- 크기는 세 번 꺾이고 불투명도는 두 번만 꺾이는 식으로 **줄마다 따로** 움직입니다
- 마름모(◆)를 누르면 **그 구간의 속도 곡선**이 나옵니다. 동그라미를 끌어 가속·감속을 만들고, 상자 밖으로 빼면 튕기거나 뒤로 당겼다 가는 움직임이 됩니다

**미리보기와 재생 헤드가 함께 움직입니다**

- 재생하면 헤드가 따라가고, **헤드를 끌면 그 순간의 모습**이 보입니다
- `Space` 재생·멈춤 · `Home` 처음으로 · `End` 끝으로
- `Ctrl+Z` / `Ctrl+Shift+Z` — 이 창만의 되돌리기라 크레딧 문서와 섞이지 않습니다

**시간 전체에 덧씌우는 손질**

- **시간 포스터화** — 초당 몇 칸으로 끊어 재생할지. 낮출수록 뚝뚝 끊기는 저프레임 필름 느낌이 납니다
- **파도 비틀기** — 화면을 물결처럼 일그러뜨립니다. 세기와 빠르기를 따로 조절합니다

만든 효과는 기본 44종과 **나란히 목록에 뜨고** (`✎` 표시), 등장·강조·퇴장 어디에든 쓸 수 있습니다.
**프리셋에 함께 저장**되므로 `.ecpreset` 으로 내보내면 효과도 딸려갑니다 — 받은 사람 화면에서도 똑같이 움직입니다.

### 🔊 소리

- **배경음악** — 크레딧 전체에 깔립니다. 페이드 인/아웃, 크레딧이 더 길면 반복
- **효과음** — 장마다 하나씩, 그 장이 나올 때 한 번
- **등장 효과음** — **요소 하나하나가 나타나는 순간** 울립니다 (속성 패널의 `효과` 칸 맨 아래). 1등이 뽀잉 튀어나올 때 `띵`, 기차가 들어올 때 `스윽` 처럼. 등장 지연을 그대로 따라가서 화면과 소리가 어긋나지 않습니다
- **묶음도 됩니다** — 덩어리 전체에 걸면 **덩어리가 나타날 때 한 번만** 울립니다 (안의 요소마다 울려서 총소리가 되지 않게). 효과가 없는 묶음에 소리만 걸어도 됩니다
- **기본 제공 소리 9종을 앱이 직접 만들어냅니다** (합성) — 저작권이 없어서 **프리셋에 담아 나눠줘도 안전합니다**
  - 효과음: 뽀잉 · 스윽 · 띵 · 반짝 · 둥 · 차오름
  - 배경음악: 따뜻한 밤 · 잔잔하게 · 조용한 피아노 (모두 이음매 없이 반복)
- 물론 **내 파일**을 넣어도 됩니다

### 📺 OBS 송출

브라우저 소스 하나만 추가하면 끝입니다. **편집 화면에서 본 것과 방송에 나가는 것이 완전히 같은 코드**로 그려집니다.

- 정지 중에는 **아무것도 그리지 않습니다** — 크레딧을 틀지도 않았는데 방송 화면에 글자가 박혀 있는 일이 없습니다
- **`▶ 이 장만 방송`** — 지금 보고 있는 장 **하나만** OBS 로 내보냅니다. 40장짜리에서 12번째 장을 확인하려고 앞의 11장을 기다릴 필요가 없고, 그 장이 끝나면 자동으로 멈춥니다. 전역 단축키·리모컨으로 트는 것은 언제나 **전체**입니다
- OBS 브라우저 소스가 새로고침돼도 알아서 다시 붙습니다
- 샘플 데이터가 켜져 있으면 화면에 **빨간 경고**가 뜹니다 (가짜 이름이 방송에 나가는 사고 방지)

### 🎮 방송 마지막에 트는 방법

크레딧을 트는 순간은 방송의 맨 끝 — 그때 앱 창을 찾으러 게임에서 빠져나오는 것 자체가 사고 위험입니다.

- **전역 단축키** `Ctrl+Alt+E` — 어느 창에 있든, 게임이 전체화면이어도 눌립니다
- **OBS 리모컨** — `도구 › 사용자 정의 브라우저 독`에 주소를 넣으면 **OBS 안에 재생 버튼**이 생깁니다
- **트레이 상주** — 창을 닫아도 꺼지지 않습니다. 수집·단축키·송출이 계속 돕니다

### 💾 프리셋 저장 · 공유

- 편집 내용은 **바꿀 때마다 자동 저장**됩니다
- 이름을 붙여 여러 벌을 남겨두고 갈아끼울 수 있습니다
- **`.ecpreset` 으로 내보내면 이미지·소리·직접 만든 효과까지 한 파일에** 담깁니다. 받은 사람은 가져오기 한 번으로 그대로 씁니다
  - 파일명이 겹치면 자동으로 이름을 바꾸고 문서 안의 주소도 같이 고칩니다
  - 앱이 만든 기본 소리는 담지 않습니다 (어느 컴퓨터에나 있으니까)
- 시작용 **템플릿 5종** — 심플 / 화려하게 / 클래식 롤 / 미니멀 / 사진 한 장

### 🔒 자기 방송 정보만

SOOP 계정으로 **OAuth 로그인**해서 본인임을 증명합니다. 남의 방송 데이터는 접근할 수 없습니다 —
채팅 SDK 자체가 로그인한 계정의 방송에만 붙습니다.

설치하면 바로 SOOP 로그인부터 시작하면 됩니다. 별도 설정은 없습니다.

### 업데이트는 앱이 알려줍니다

**한 번만 손으로 설치하면, 그 뒤로는 릴리스 페이지에 다시 갈 일이 없습니다.**

- 앱을 켜면 새 버전이 있는지 확인하고, 있으면 위쪽에 `0.4.0 새 버전 [받기]` 가 뜹니다
- **받는 건 누를 때만 시작합니다** — 방송 중에 말없이 수십 MB 를 받아가지 않습니다
- 다 받으면 `준비됨 [지금 설치]` 로 바뀝니다. **재시작을 강요하지 않습니다** — 방송 중에 앱이 꺼지면 그날 수집이 거기서 끊기기 때문입니다
- **`지금 설치` 를 누르면** 앱이 껐다 켜지면서 설치가 끝납니다. 수집·송출 중이면 한 번 물어봅니다
- 눌러두지 않아도 **트레이의 `완전히 종료` 로 끌 때** 설치되고, 끝나면 앱이 스스로 다시 켜집니다
- ⚠️ **창의 X 는 끄는 것이 아니라 트레이로 내려가는 것입니다** — 그것만으로는 설치되지 않습니다
- **수집 중이거나 크레딧을 송출하는 동안에는 확인조차 하지 않습니다.** 그때 할 일은 방송이지 업데이트가 아닙니다
- 바뀐 부분만 받아서 매번 전체 용량을 내려받지 않습니다
- 확인이 실패하면 `직접 받기` 버튼으로 릴리스 페이지가 열립니다

> 지금 쓰는 버전이 `0.3.0` 보다 낮으면 업데이트 확인 기능 자체가 없습니다 — **다음 한 번만** 손으로 받으면 그 뒤로는 자동입니다.

## OBS 설정

1. **소스 `+` → 브라우저**
2. URL: `http://localhost:7396/overlay`
3. 너비 `1920` / 높이 `1080`
4. **"소스가 보이지 않을 때 종료" 체크 해제** — 방송 내내 연결을 유지해야 합니다
5. 소리를 쓴다면 **"OBS를 통해 오디오 제어" 켜기** — 안 켜면 내 스피커에서만 나고 **시청자는 못 듣습니다**

리모컨을 쓰려면 **도구 → 사용자 정의 브라우저 독**에 `http://localhost:7396/remote` 를 추가하세요.

> 앱의 **🔗 연결** 버튼에서 두 주소를 바로 복사할 수 있습니다.

## 내 데이터는 어디에 있나요

전부 **내 컴퓨터에만** 저장됩니다. 서버로 보내는 것은 아무것도 없습니다.

```
%APPDATA%\endcredit\
├─ current-preset.json     지금 편집 중인 것
├─ presets\                이름 붙여 저장한 것들 + 자동 백업
├─ assets\                 넣은 이미지·소리
├─ sessions\<날짜>\        방송 이벤트 원본 로그
├─ tokens.enc              로그인 토큰 (암호화됨)
└─ settings.json           앱 설정
```

로그인 토큰은 **윈도우가 이 컴퓨터·이 계정에 묶어 암호화**해서 보관합니다.
파일을 통째로 복사해 가도 다른 컴퓨터에서는 풀리지 않습니다.
암호화를 쓸 수 없는 환경이면 **아예 저장하지 않고** 매번 다시 로그인합니다 — 평문으로 떨구지 않습니다.
로그아웃하면 파일이 지워집니다.

## 새 버전 내는 법 (만든 사람용)

**버전은 `package.json` 한 곳에만 적습니다.** 화면에 보이는 버전도, 설치 파일 이름도,
자동 업데이트가 비교하는 값도 전부 여기서 나옵니다 — 손으로 적는 자리를 두면 반드시 어긋납니다.

```bash
# 1. 앱을 완전히 끕니다 (트레이 포함) — 켜져 있으면 설치 파일이 반쪽으로 나옵니다
npm version patch          # 0.3.0 → 0.3.1  (기능 추가면 minor)
npm run dist               # 빌드 → dist\ 에 설치 파일 + latest.yml
```

그다음 **GitHub 웹에서 손으로 올립니다.**

1. `Releases` → `Draft a new release`
2. 태그 `v0.3.1` (새로 만들기) · Target `main` · 제목 `0.3.1`
3. `dist\` 의 **두 파일**을 끌어다 놓기 — `endcredit-0.3.1-setup.exe` · `latest.yml`
4. `Publish release`

**자동 업로드(`electron-builder --publish`)는 쓰지 않습니다.** 세 번 시도해 세 번 다
실패했습니다 — 토큰 인증, 초안이 두 개로 갈리는 버그, 그리고 `latest.yml` 이 실제 설치
파일과 어긋나는 문제. 웹 업로드는 토큰도 필요 없고 실패할 구석이 없습니다.

- **`latest.yml` 이 없으면 자동 업데이트는 영영 아무것도 못 찾습니다.** 반드시 함께 올리세요.
  이 파일은 `npm run dist` 가 끝난 뒤 **완성된 설치 파일에서 직접** 만들어지므로
  (`scripts/make-latest-yml.js`) 내용이 어긋날 일이 없습니다.
- 설치 파일이 **96MB 대**인지 확인하세요. 수백 KB면 앱이 켜진 채로 빌드된 반쪽입니다
  (스크립트가 걸러내고 멈춥니다).
- **`migrate.ts` 를 꼭 확인하세요.** 자동 업데이트는 사용자가 모르는 사이에 버전을 건너뛰게
  만듭니다 — 예전 문서를 못 여는 버전이 조용히 깔리면 방송 직전에 터집니다
