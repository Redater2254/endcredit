방송이 끝날 때, 오늘의 기록을
영화 엔딩크레딧처럼 올려보냅니다

방송 중에 켜두기만 하면 endcredit 이 채팅·별풍선·구독 같은 이벤트를 실시간으로 모읍니다. 방송 마지막에 단축키 한 번이면, 오늘 함께해준 사람들의 이름이 화면에 올라갑니다.

비슷한 도구는 있었지만

대부분 만든 사람의 방송에 맞춰져 있어서, 남이 쓰면 커스텀이 거의 불가능했습니다. 색 하나, 문구 하나 바꾸려 해도 손댈 수가 없었죠.

endcredit 은 반대로 만들었습니다

모든 것이 사용자 것입니다. 글꼴·색·위치·효과·배경음악·효과음까지 전부 바꿀 수 있고, 완성한 구성은 파일 하나로 묶어 다른 스트리머에게 그대로 줄 수 있습니다.

주요 기능

모으고, 꾸미고, 틀어줍니다

방송 중 데이터 수집부터 OBS 송출까지 앱 하나에서 끝납니다.

오늘의 기록을 자동 집계

방송 중에 켜두면 SOOP 채팅 서버에 붙어 이벤트를 실시간으로 모읍니다.

  • 앱이 중간에 꺼져도 로그로 집계를 복원
  • 닉네임 뒤 (2) 표시가 붙어도 한 사람으로 집계
  • 스트리머 본인 채팅은 순위에서 제외

슬라이드 편집기

파워포인트처럼 장(슬라이드)을 만들고 요소를 자유롭게 배치합니다.

  • 텍스트 · 이미지 · 순위 목록 · 등수 하나 · 도형 · 🚂 기차
  • 자석(스냅) · 묶기 · 정렬 · 범위 선택 · 올가미(L)
  • 도형을 끌어서 그리기(R) — 그라데이션 · 테두리 여러 겹 · 그림자 여러 겹
  • 이미지에도 테두리·그림자 — 그림자는 뚫린 PNG 의 인물 윤곽을 따라갑니다
  • 명단 자동 흐름 — 상자 끝에 닿으면 다음 열 위로 넘어가 계속 쌓입니다
  • 그림은 탐색기에서 끌어다 놓기 · 파일 창은 지난번 폴더에서 열립니다
  • 고급 개체 — 여러 요소를 한 줄로 접고, 두 번 누르면 그 안이 열립니다 (사본은 연결)
  • 레이어 병합(Ctrl+E) — 여러 요소를 한 장의 이미지로 굽기
  • 재생 타임라인 — 아무 시점이나 찍어 그 순간을 세워 놓고 편집
  • 글자 자동 맞춤 · 화면 크기(세로 9:16 쇼츠까지)
  • 요소칸 우클릭으로 잠금·순서·효과 복사 · 되돌리기 100단계

글자를 그 자리에서

텍스트를 두 번 클릭하면 캔버스 위에서 바로 편집됩니다.

  • 포토샵처럼 일부만 드래그해 색·크기·굵기 변경
  • “1등”은 노랗고 크게, 이름은 희게 — 한 줄 안에서

데이터 필드

글 안에 자리표시자를 넣으면 방송이 끝날 때 실제 값으로 바뀝니다.

  • {chatRank.1.name} → 오늘의 수다왕 이름
  • 명단 전체도 한 번에 {newSubscribers.list}
  • 오늘 날짜·시각 {now.year}년 {now.month}월 {now.day}일
  • 끌어다 놓으면 그 자리에 만들어집니다

효과 46종

등장 19 · 강조 5 · 퇴장 11 · 화면 전체 11.

  • 등장·강조·퇴장이 서로 다른 칸이라 한 요소에 셋 다
  • 타자기 · 흐르는 자막 · 색종이 · 불꽃놀이 · 눈 · 하트 …
  • 묶음에는 묶음만의 효과 — 안쪽 요소와 따로 움직입니다
  • 마우스만 올려도 그 자리에서 미리 재생

효과를 직접 만들기

고르는 것으로 부족하면 직접 만듭니다. 프리미어 프로의 «효과 컨트롤» 과 같은 방식이고, 크레딧을 보면서 다듬을 수 있도록 전용 창으로 열립니다.

  • 위치 X·Y, 크기 X·Y, 회전, 기울이기 X·Y, 불투명도, 흐림이 각자 트랙
  • ⏱ 를 켜고 재생 헤드에서 숫자를 바꾸면 키프레임이 찍힙니다
  • 파란 숫자를 끌면 값이 바뀌고, 누르면 고쳐 씁니다
  • 구간마다 속도 곡선을 그래프로 — 끌어서 가속·감속·튕김
  • 헤드를 끌면 그 순간의 모습이 그대로 보입니다
  • 시간 포스터화 · 파도 비틀기를 덧씌울 수 있습니다
  • 만든 효과도 프리셋에 담겨 그대로 전달됩니다

배경과 테마

장마다 배경 이미지를 깔고, 앱은 밝게도 어둡게도 쓸 수 있습니다.

  • 채우기 · 전체 보기 · 늘이기 + 불투명도 · 흐림
  • 한 번에 모든 장에 같은 배경 적용
  • 밝은 테마 / 어두운 테마 — 방송 화면은 그대로

소리도 함께

크레딧 전체에 깔리는 배경음악과 장마다 하나씩 넣는 효과음.

  • 기본 제공 소리 9종을 앱이 직접 합성 — 저작권 걱정 없음
  • 배경음악은 페이드 인/아웃 · 이음매 없이 반복
  • 등장 효과음 — 요소가 나타나는 순간 울립니다 (묶음은 덩어리째 한 번)
  • 물론 내 파일을 넣어도 됩니다

OBS 송출

브라우저 소스 하나만 추가하면 끝. 편집 화면과 방송 화면이 완전히 같은 코드로 그려집니다.

  • 정지 중에는 아무것도 그리지 않음 — 글자가 박혀 있을 일 없음
  • 브라우저 소스를 새로고침해도 알아서 다시 연결
  • 샘플 데이터가 켜져 있으면 화면에 빨간 경고 표시
  • “이 장만 방송” — 보고 있는 장 하나만 OBS 로, 끝나면 자동 정지

게임 중에도 바로 재생

크레딧을 트는 순간은 방송의 맨 끝. 그때 앱 창을 찾으러 게임에서 빠져나올 필요가 없습니다.

  • 전역 단축키 Ctrl+Alt+E — 전체화면 게임 중에도
  • OBS 사용자 정의 브라우저 독에 재생 버튼 리모컨
  • 트레이 상주 — 창을 닫아도 수집·송출은 계속

SOOP 계정으로 로그인

설치가 끝나면 앱을 켜고 SOOP 로그인부터 하면 됩니다. 별도 설정은 없습니다.

로그인은 본인 확인용입니다. 채팅 연결 자체가 로그인한 계정의 방송에만 붙기 때문에, 남의 방송 데이터는 접근할 수 없습니다.

“Windows의 PC 보호” 창이 뜬다면

정상입니다. endcredit 은 개인이 만든 앱이라 코드 서명 인증서가 없습니다. 인증서는 개인 개발자가 매년 유지하기에는 비용이 부담스러운 물건이라, 그 대신 Windows가 “처음 보는 파일”로 판단해 한 번 확인 창을 띄웁니다. 설치 파일에 문제가 있다는 뜻은 아닙니다.

Windows의 PC 보호
Windows Defender SmartScreen에서 인식할 수 없는 앱의 시작을 차단했습니다.
추가 정보 → 실행

추가 정보를 누르면 아래에 실행 버튼이 나타납니다. 그걸 누르면 설치가 계속됩니다. 몇 번 설치·실행이 쌓이면 이 창은 더 이상 뜨지 않습니다.

궁금한 것들

무료인가요?

네, 완전 무료입니다. 결제도 계정 등록도 없습니다. MIT 라이선스로 소스 코드까지 공개되어 있습니다.

내 데이터는 어디에 저장되나요?

전부 내 컴퓨터에만 저장됩니다. 서버로 보내는 것은 아무것도 없습니다.

%APPDATA%\endcredit\ ├─ current-preset.json 지금 편집 중인 것 ├─ presets\ 이름 붙여 저장한 것들 + 자동 백업 ├─ assets\ 넣은 이미지·소리 ├─ sessions\<날짜>\ 방송 이벤트 원본 로그 └─ settings.json 앱 설정

로그인 토큰은 윈도우가 이 컴퓨터·이 계정에 묶어 암호화해서 보관합니다. 파일을 통째로 복사해 가도 다른 컴퓨터에서는 풀리지 않고, 로그아웃하면 지워집니다.

맥이나 리눅스에서도 되나요?

Windows 전용입니다. 전역 단축키와 트레이 상주처럼 Windows에 맞춰 만든 부분이 있어서, 지금은 Windows 설치 파일만 제공합니다.

방송을 안 해도 미리 볼 수 있나요?

네. 샘플 데이터를 켜면 시청자 없이도 완성된 모습을 그대로 볼 수 있습니다. 방송 전에 미리 만들어 두고 확인하기 좋습니다.

샘플 데이터가 켜져 있는 동안에는 오버레이 화면에 빨간 경고가 뜹니다. 가짜 이름이 실수로 방송에 나가는 사고를 막기 위한 장치입니다.

방송 중에 앱이 꺼지면 오늘 기록이 날아가나요?

아닙니다. 모든 이벤트는 줄 단위 로그 파일로 계속 쌓입니다. 앱을 다시 켜면 그 로그를 읽어 집계를 복원합니다.

다른 스트리머가 만든 구성을 받아 쓸 수 있나요?

됩니다. 만든 구성을 .ecpreset 파일로 내보내면 이미지와 소리까지 한 파일에 담깁니다. 받은 사람은 가져오기 한 번이면 그대로 씁니다. 파일명이 겹치면 알아서 이름을 바꿔줍니다.

앱이 직접 만들어내는 기본 소리 9종은 저작권이 없어서, 프리셋에 담아 나눠줘도 안전합니다.

남의 방송 데이터도 볼 수 있나요?

불가능합니다. SOOP 계정으로 로그인해 본인임을 증명하고, 채팅 연결 자체가 로그인한 계정의 방송에만 붙습니다.

아직 BETA라던데, 써도 괜찮나요?
