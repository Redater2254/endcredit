# 브랜드 이미지 넣는 곳

여기에 파일을 두고 `npm run icons` 를 실행하면 필요한 크기가 전부 만들어집니다.

| 파일 | 규격 | 쓰이는 곳 |
|---|---|---|
| `icon.png` | **1024×1024 정사각형 PNG, 배경 투명** | 실행 파일·창·트레이·설치 파일 |
| `logo.png` | 가로형, 폭 1200px 이상, 배경 투명 (선택) | 앱 화면 좌측 상단 |

## icon.png 만들 때 주의

- **16px 에서도 알아볼 수 있어야 합니다.** 트레이 아이콘이 16px 입니다.
  얇은 선, 작은 글자, 자잘한 디테일은 그 크기에서 뭉개져 얼룩으로 보입니다.
- 도형 하나 + 색 두세 개면 충분합니다.
- 가장자리에서 **8% 정도 여백**을 두세요. 윈도우가 아이콘을 이런저런 자리에
  얹을 때 꽉 찬 그림은 잘려 보입니다.
- 배경은 **투명**으로. 사각형 배경이 필요하면 그림 안에 직접 그려 넣으세요.

## 파일이 이것뿐인가요?

- **PNG 대신 SVG 밖에 없다면**: 벡터 편집기에서 1024×1024 PNG 로 한 번만 내보내 주세요.
- **512 나 256 밖에 없다면**: 그대로 둬도 만들어지지만 큰 크기가 흐려집니다.
- **정사각형이 아니면**: 찌그러집니다. 여백을 넣어 정사각형으로 맞춰 주세요.
